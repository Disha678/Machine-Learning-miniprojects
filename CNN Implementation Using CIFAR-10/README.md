# CNN Implementation Using CIFAR-10

## Description

The CNN Implementation project demonstrates the implementation of a Convolutional Neural Network (CNN) model for image classification using the CIFAR-10 dataset.

The model learns important features from images using convolutional and pooling layers and classifies the images into different categories.

## Dataset Used

* CIFAR-10 Dataset
* Source: Kaggle
* 60,000 color images
* Image size: 32 × 32 pixels
* 10 different classes
* 50,000 training images
* 10,000 testing images

## Model Used

* Convolutional Neural Network (CNN)
* LeNet-5 Variant

## Working Principle

1. The CIFAR-10 dataset is loaded into the program.
2. The training and testing datasets are separated.
3. The images are normalized to improve model training.
4. The CNN model is created using convolutional, pooling, and fully connected layers.
5. The model is trained using the training dataset.
6. The trained model is evaluated using the testing dataset.
7. The model predicts the classes of unseen images.
8. The model performance is evaluated using accuracy and loss.
